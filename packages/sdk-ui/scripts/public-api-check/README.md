# public-api-check

`public-api-check` validates the tag-specific public API barrels and the non-public entry points of `@sisense/sdk-ui`.

## Need

- Keep export-policy validation in one dedicated place.
- Ensure tag-scoped barrel files (for example `sisense-internal.ts`) export only declarations with the required tag.
- Forbid wildcard exports in these barrel files (`export *` and `export * as`).
- Ensure the non-public entry points (`@sisense/sdk-ui/internal`, `@sisense/sdk-ui/sisense-internal`) export nothing outside their level.

## Result

Running the script:

- passes when all named exports in configured barrel files resolve to declarations with required tags;
- fails with detailed violations (export name, reason, file, line) when:
  - wildcard exports are used,
  - an export declaration cannot be resolved,
  - required tag is missing;
- fails when an entry point exports a name without its level's tag.

Changes to the sisense-internal surface show up in review through `.reports/doc-tag-usage-report/TAG_USAGE_REPORT_SISENSE_INTERNAL.txt` (regenerated by `yarn docs:gen:md`, checked in CI).

## Structure

- `index.cjs` - script entry point with `PUBLIC_API_ENTRIES`, `ENTRY_SURFACES` and the `validatePublicApiEntries(...)` call.
- `validate-public-api-entries.cjs` - reusable validation logic.

## Configuration

Edit `PUBLIC_API_ENTRIES` in `index.cjs` to add more barrel files and tags, and `ENTRY_SURFACES` to add entry points.
