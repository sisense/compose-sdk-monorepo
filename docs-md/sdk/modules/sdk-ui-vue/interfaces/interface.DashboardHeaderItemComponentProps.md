# Interface DashboardHeaderItemComponentProps

Props passed to a [DashboardHeaderItemComponent](../type-aliases/type-alias.DashboardHeaderItemComponent.md) when it is rendered.

## Properties

### size

> **size**: `object`

The size resolved for the item by the header layout, with defaults applied.

#### Type declaration

> ##### `size.height`
>
> **height**: `number`
>
> Fixed height of the item, in pixels.
>
> ##### `size.width`
>
> **width**: `number`
>
> Fixed width of the item, in pixels.
>
>
