# Type alias KpiBeforeRenderHandler <Badge type="beta" text="Beta" />

> **KpiBeforeRenderHandler**: (`renderOptions`) => [`KpiRenderOptions`](type-alias.KpiRenderOptions.md)

A handler function that allows to customize the computed KPI render options
before the card is rendered. The returned options are then used when painting the card.

## Parameters

| Parameter | Type |
| :------ | :------ |
| `renderOptions` | [`KpiRenderOptions`](type-alias.KpiRenderOptions.md) |
