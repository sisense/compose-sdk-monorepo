# Type alias FilterTileMenuItem

> **FilterTileMenuItem**: [`FilterTileMenuActionItem`](../interfaces/interface.FilterTileMenuActionItem.md) \| [`FilterTileMenuSubmenuItem`](../interfaces/interface.FilterTileMenuSubmenuItem.md)

A single item in the filter tile menu, discriminated by its `type`.

Items are contributed through [FilterTileMenuConfig.items](../interfaces/interface.FilterTileMenuConfig.md#items) and are rendered after the
built-in items the tile adds itself (for example "Lock").
